# Lince Browser 1.0.1

This update fixes a display problem that could appear right after searching from the address bar.

## Fixed

- Submitting a search or address no longer leaves a black, keyboard-sized area at the bottom of the next page. The page now waits until the keyboard has fully closed before it takes back that space.
- The address bar no longer mistakes its own closing keyboard for a website's text field.
