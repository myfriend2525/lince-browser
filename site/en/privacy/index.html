Privacy Policy

Last updated: 20 October 2026

Summary Browser data Lince Sync External services Your control Security This website Contact

Lince Browser is designed to keep your browsing data on your device. Lince runs no analytics service and no hosted sync service, and the Lince team does not receive your browsing history through the app.

Short version

Local features stay local. Network features connect only when you use or enable them. Lince Sync sends end-to-end encrypted tab data to a server you choose.

1. Scope

This policy covers Lince Browser for Android in both its GeckoView and System WebView editions, and this website. Websites you visit, search providers, sync server operators and other services have their own privacy practices.

2. Data processed by Lince

Depending on the features you use, Lince may process tabs, URLs, page titles, browsing history, favorites, profiles, site permissions, downloads, Reader content, saved page previews and local privacy-protection statistics.

This information is stored on your device for the features you choose, and Lince does not send it to the Lince team. Private tabs, private trails, private permissions and private Reader state are never written to persistent storage.

Your operating system, the browser engine, websites you visit and extensions you install may process additional data independently of Lince.

3. Lince Sync

Lince Sync is optional and self-hosted. You provide the server endpoint and credentials and decide which data types to synchronize.

During setup

  • Server endpoint and username: stored on your device as configuration.
  • Server password: sent to your server during enrollment.
  • E2EE passphrase: used on the device to create or unlock encryption keys. It is never sent to the server.
  • Device name and icon: encrypted on the device before upload.

What is synchronized

When tab sync is enabled, Lince processes eligible HTTP and HTTPS tab URLs, titles, order and pin state. Private tabs, browser-internal pages and local files are excluded. Everything is encrypted on the device before transmission.

What the server can observe

The server stores encrypted payloads plus the metadata needed to operate sync, such as workspace and device identifiers, revisions, payload sizes and timestamps. It does not receive tab URLs, tab titles, device names, profile icons, your passphrase or your keys in plaintext.

The server operator or hosting provider may separately process network metadata, including IP addresses and request logs. Those practices are controlled by whoever operates the server you choose.

4. Websites and external services

Browsing sends requests to the websites you choose. Optional features such as search suggestions, search providers, translation, sharing, external apps or extensions contact their services only when you configure, enable or use them. Lince never requests remote search suggestions for anything you type in private mode.

In the GeckoView edition, if you enable encrypted DNS, DNS queries are sent to the provider you configure. Firefox extensions you install run with the permissions you grant them and follow their authors’ policies. uBlock Origin, built into this edition, filters on your device.

If you use Google Cast, Google’s Cast Sender SDK is activated and may send diagnostic and usage information to Google to operate Cast. Media URLs and metadata are sent only to the Cast device you select, and Lince does not store them. Google’s processing is governed by the Google Privacy Policy.

Lince does not sell personal information and does not use your browsing data for advertising or profiling unrelated to browser features.

5. Retention and your control

Local data remains until you clear it, remove the profile, reset the feature or uninstall the app, subject to platform backup behavior. Lince Sync ciphertext remains on your server until it is removed according to that server’s operation and backups.

You can disable sync, revoke permissions, clear browsing data or delete data from your server. Losing your Lince Sync passphrase makes encrypted data unrecoverable.

6. Security

Lince Sync uses Argon2id for passphrase-based key derivation, AES-256-GCM for authenticated encryption, HKDF-SHA-256 for key separation and independently generated P-256 device identities.

No system can guarantee absolute security. An unlocked device, malware, a compromised extension or an untrusted transport to the server may expose information outside Lince’s protection.

7. Children

Lince Browser is a general-purpose browser and is not directed to children. The project does not knowingly collect personal information from children.

8. This website

This website is static: it uses no cookies, analytics or forms. The hosting service may log technical access data such as IP addresses. The homepage illustration and video are loaded from an external server, which also receives that technical data when it serves them.

9. Changes

Material changes will be published on this page with their update date. The project repository history provides a public record of every revision.

10. Contact

For privacy questions or support, open an issue on the Lince Browser issue tracker on GitHub. For a security-sensitive report, do not post sensitive details publicly; open a short issue asking for a private channel.
